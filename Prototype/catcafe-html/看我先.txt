猫咖营业计划 · HTML 复刻件
================================

怎么玩
------
双击「猫咖营业计划.html」，用 Chrome / Edge 打开即可。不用装任何东西，不联网。
进度存在浏览器本地，换浏览器或清缓存会重来。

这是什么
--------
Unity 版猫咖的浏览器复刻件，用来快速看表现、试手感。三个界面都在：
开始界面 → 大厅（收集册 / 猫咪招募 / 罐头 / 绒毛）→ 局内（棋盘 / 名册 / 结算 / 三选一），
房东奶奶的教程字条也按原表触发。

布局坐标、字号、颜色、动画时长、收益公式全部来自项目的正式配置表，不是照着截图描的。

哪些没做
--------
· 营业道具（items）只登记和展示，不套用它的收益改写，所以金额比正式版偏低。
· 繁育、下班券、消耗类事件、无尽模式没有实现；未移植的规则一律按 0 算，不编数值。
· 背景音乐有（按场景切歌、交叉淡入、设置里能调音量）；点击界面任意处才会起播，
  这是浏览器的自动播放限制。按钮音效也有，音量都能在设置里调。
· 没有 PV、没有多存档槽。
· 大厅的绒毛/罐头按配置表的公式走，但存在浏览器里，和 Unity 存档不通。

关于画质
--------
为了能发出去，这一份里的图做过等比缩小（棋子 256px、开始界面 1536×864，
都不低于实际显示尺寸）。项目 Assets 里的源图一个字节都没动。
