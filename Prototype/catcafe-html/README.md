# 猫咖营业计划 · HTML 复刻件

Unity 版《猫咖营业计划》的浏览器复刻件，用来快速看表现、试手感。

**在线试玩**：https://sakurie.github.io/catcafe-html/

三个界面都在：开始界面 → 大厅（收集册 / 猫咪招募 / 罐头 / 绒毛）→ 局内（棋盘 / 名册 / 结算 / 三选一），
房东奶奶的教程字条按原表触发。布局坐标、字号、颜色、动画时长、收益公式全部来自项目的正式配置表。

## 不是完整对局

- 营业道具只登记和展示，不套用它的收益改写，所以金额比正式版偏低
- 繁育、下班券、消耗类事件、无尽模式没有实现；未移植的规则一律按 0 算
- 背景音乐和按钮音效有，音量可在设置里调；点一下页面才会起播（浏览器自动播放限制）
- 进度存在浏览器 localStorage，换浏览器或清缓存会重来

## 本地打开

克隆后直接双击 `index.html` 即可，不用起服务、不用联网。
