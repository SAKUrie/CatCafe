## 1. 一句话与循环

局内开一局猫咖（幸运房东棋盘）赚金币付房租；局外收集猫咪填图鉴——核心驱动是
**"我想看看下一次营业能不能繁育出一只新的猫。"**

```
整备界面（猫咖大厅）
  看猫游走 / 收小费 / 查图鉴 / 猫咪招募 / 培养猫咪
        │ 开始营业
        ▼
局内一局（棋盘经营，3关：35 / 85 / 175 金币）
  繁育出幼崽 → 图鉴点亮新品种；盘面上的猫每波次 20% 掉绒毛
        │ 打烊 或 失败 / 通关
        ▼
罐头结算 → 回到大厅 → 新猫出现在大厅和下局奖励池
```

场景流程：开始界面（CatCafeStart）→ 整备界面（CatCafeHome）→ 局内（CatCafeDemo）→ 回整备。

## 2. 两种货币（刻意隔离）

| 货币 | 生命周期 | 用途 |
| --- | --- | --- |
| 金币 | 只存在于一局之内 | 付关卡房租（35 / 85 / 175） |
| 罐头 | 永久（存档） | 呼朋唤友、（二期）喂食与买装饰 |

罐头有两条互不相干的收入：

**收入 A：局末折算**（打烊 / 失败 / 通关时自动结一次，一局只结一次）

```
罐头 = 剩余金币 × 20%（向下取整）
     + 清关数 × 10
     + 本局首次发现数 × 20
     + 失败保底：总回合数 ÷ 2（向下取整，仅一关都没过时给）
```

**收入 B：收钱罐**（大厅里的放置收益，离线也涨）

```
0.2 罐头/分钟 × 已收集猫数，攒满 50 封顶，手动点击收取
```

设计意图：金币只折 20% 带出局外，防止局外积累反过来冲垮局内难度曲线。

## 3. 图鉴（18 只猫）

| 分类 | 品种 | 获得方式 | 立绘 |
| --- | --- | --- | --- |
| 初始 ×4 | 黑猫、白猫、橘猫、灰虎斑 | 开局即有 | 有 |
| 一级繁育 ×6 | 蓝猫、暹罗、狸花、燕尾服、玳瑁、橘白 | 基础三色两两配对 | 橘白缺图 |
| 二级繁育 ×2 | 奶牛猫、三花猫 | 一级产物长大后再配对 | 有 |
| 特殊配方 ×4 | 英短、金渐层、布偶、长毛猫 | 深层配对（正式版挂特殊条件） | 全缺 |
| 变异 ×2 | 异瞳猫、德文卷毛 | 繁育时小概率；不进呼朋唤友表，只能偶遇 | 全缺 |

规则要点：

- 局内育儿窝孵出的是**幼崽**（每相邻客人 +3 金币，不能繁育）；图鉴点亮的是其**成年形态**
- 未解锁的猫显示**剪影 + 谜面提示**（变异猫无提示）
- 重复孵出已有品种只累计「见过 ×N」；绒毛由营业掉落与现实时间自然增长独立累计（见 §5）
- **解锁即入池**：图鉴点亮后，该品种按稀有度进入局内三选一奖励池；没解锁的猫绝不在局内出现（燕尾服、奶牛、三花已从初始池移出，改为繁育解锁）

## 5. 绒毛与猫咪招募 · 呼朋唤友（脸黑保险，2026-08-19 更新）

绒毛有两种来源：①每波次结束时，盘面上每只**成年猫**各按
`meta_fur_drop_chance`（默认 20%）判一次，中了给自己品种 +1 撮；②每个已认识品种
按现实时间自然积攒，默认每 60 分钟 +1 撮，自然增长最多补到每品种 12 撮。
三个自然增长参数分别由 `meta_fur_natural_interval_minutes`、
`meta_fur_natural_amount_per_interval`、`meta_fur_natural_cap_per_breed` 配置。
营业掉落可超过自然上限；绒毛只影响局外，不进入局内数值。

**猫咪招募 = 呼朋唤友**：让已经住进猫咖的猫，带着绒毛和罐头出门，把新朋友请回来。

```
呼朋唤友 = 邀请者A的绒毛 ×fur_a [+ 邀请者B的绒毛 ×fur_b] + 罐头 ×cans
产出     = 直接点亮该品种图鉴
```

| 目标档位 | 邀请者 | 消耗（当前表值） |
| --- | --- | --- |
| 少见（蓝猫/燕尾服/暹罗/橘白/狸花/玳瑁） | 1 位初始猫 | 绒毛 6 ＋ 罐头 40 |
| 少见（奶牛） | 1 位（燕尾服） | 绒毛 5 ＋ 罐头 60 |
| 稀有（三花/英短/金渐层/布偶/长毛） | **2 位** | 绒毛 4+8 或 4+4 ＋ 罐头 100~120 |

规则要点：

- 邀请者**不是父母**，产物也不落到棋盘上——这不是合成，是"猫的朋友总是猫"。
- 邀请者必须已经入住（图鉴已点亮）才叫得动。
- 变异猫（异瞳、德文）不进邀请表——只能在营业时偶遇，保持稀缺。
- 解锁时沿用与局内诞生完全相同的图鉴揭晓页。

设计意图：局内育儿窝靠运气是惊喜，猫咪招募是保底进度条。主动营业能更快获得绒毛，
暂时不营业时也会随现实时间推进。邀请路线在工作簿的 `Invite` 页，自然增长参数在
`Settings` 页。

## 6. 猫咪培养（⚠️ 当前未实装）

## 7. 整备界面（猫咖大厅）

- **实景大厅**：已收集的猫全员游走（走停、转身、点击弹名牌），收集进度 = 店面热闹程度
- **家具**：吧台、夜窗、货架、育儿窝、猫粮碗、猫砂盆（静态摆设；装修系统属二期）
- **收钱罐**：右下角，实时显示累积量与液面，点击收取（见 §2 收入 B）
- **图鉴 / 猫咪招募**：全屏面板
- **开始营业**：进局内
