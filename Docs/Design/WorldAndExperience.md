# 猫咖营业计划 · 世界观与体验设计

> 2026-08-13 店长拍板（对应 MetaGameDesign §1 决策 D8）。
> 目标：消除局内/局外割裂感，让玩家不出戏。
> **已否决**：昼夜同店设定（局内=白天、局外=夜晚）——不要再提案。
> 同日补充拍板：**主角是一只猫**（接店的店长猫）；**房东是和蔼老太太「房东奶奶」**，
> 她知道店长是猫，也认真把它当能独当一面的孩子。教学由房东字条承载，见 §8。

---

## 1. 割裂感的三个来源（诊断）

1. **进度会凭空蒸发**：中途退出，这一局像没发生过，没有叙事解释。最出戏的一刻。
2. **两个世界没有时空关系**：玩家不知道转盘间和大厅是不是同一个地方。
3. **规则裸露**：目标金额、回合限制、失败重开都没有戏中人背书。

---

## 2. 框架：一家店，两种状态

**局内 = 挂着「营业中」木牌的店；局外 = 翻成「歇业」牌之后的店。**

同一个空间的两种状态，不承诺时间（歇业不等于夜晚）。

| 已有元素               | 归位                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| 「开始营业」按钮       | 把门牌翻到「营业中」                                                                          |
| 「打烊返回猫咖」       | 把门牌翻到「歇业」                                                                            |
| 局内 BGM（3 首高节奏） | 营业的忙碌                                                                                    |
| 局外 BGM（11 首舒缓）  | 歇业的闲适                                                                                    |
| 场景转场（待做）       | **翻门牌过场**：纸艺木牌翻面 + 门铃/落锁音效，同时充当加载转场（PageFlowAndUI P0 缺口） |

---

## 3. 幸运房东：规则的化身

从未露面（至多一只手、一个影子、一张字条）的**房东奶奶**——和蔼、细心、稍微有点絮叨的
老太太，承担所有"游戏规则味"：

| 裸规则             | 房东化                                                               |
| ------------------ | -------------------------------------------------------------------- |
| 阶段目标 35/85/175 | **房租单**：贴在门上的字条。"试营业的房租是 35 金币。慢慢来。" |
| 波次限制（5/5/6）  | 她的记账周期："5 波客人之后，我来收房租。"                           |
| 失败可重开         | "这次账先放下，回去调整一下名册，我们明天再试试。"                   |
| 4×4 转盘          | 她留下的**招财装置**——店里的一波客人被它浓缩成一次转动       |
| 三选一             | 每波客人散去，门口会多出些"想进店的"——挑一个记进名册               |
| 新手引导           | 房东字条系统，天然教学载体（定稿见 §8）                             |

成本控制：**没有剧情系统**，只有一套文案口吻 + 至多一张立绘/字条视觉。

---

## 4. 客猫与住猫（衔接亲密度 D4–D7）

- 局内出现的猫 = 被店吸引来的**客猫** + 来帮忙的**住猫**（随行猫="今天带哪只看店"）。
- **首次发现 = 这只猫决定留下来住**。新发现弹窗的戏剧句："它没有走。"
- 打烊后金币→罐头 = **用今天的流水给猫进货**；其余 80% 是房租水电食材，
  RunSummary 账本一行带过，20% 折算从数值损耗变成经营开销。

---

## 5. 退出体验：这一局永远不会被偷走

原则：**退出 ≠ 失去，退出 = 时间暂停**。

### 5.1 挂起存档（RUN-1）

- **回合边界检查点**：回合结算完成 / 三选一落定 / 阶段转换后，写 `catcafe_run.json`
  （与 meta 存档分离；打烊或失败重开时删除）。
- 存：金币、阶段、回合、双券、清单、棋盘 16 格、持有物品、**未决三选一的选项 key**
  （防退出重开刷选项）。
- 中途杀进程 → 回退到最近检查点（棋盘停在"等待营业"），损失至多半个回合的动画。
- **回归 UX**：开局页若有营业存档，主按钮变为「店还开着 —— 继续营业（第 2 天 · 回合 3）」；
  进局内 Toast："欢迎回来，客人们还等着呢。"
- 已知取舍：RNG 不落盘，退出重进可刷转盘结果。单机休闲游戏 MVP 接受；
  表留 `run_save_seed` 开关位，后续要堵再堵。

### 5.2 主动离开 = 提前打烊

现有"打烊返回猫咖"路径（结算+二次确认）只换文案：
"现在打烊，就会按目前的流水结算今天的营业。大家都有些困啦，你也想回去休息了吗？"

口吻规范（房东奶奶，2026-08-13 定稿）：

- 把主角当成认真接店的晚辈，不把它当宠物训话。
- 温柔提醒，不挖苦玩家，也不阴阳怪气。
- 偶尔使用"啦、呀、慢慢来"，但不要每句都有。
- 猫咪笑点来自生活细节（爪印、坐垫、打哈欠），不反复强调"猫居然会开店"。
- **唯一豁免（2026-08-14）**：房东奶奶可以放狠话，但只在"立 flag 又当场食言"这一组里用——
  开局交店说"赚不够就住不下去"，首次失败立刻反转成"我怎么会赶你走呢……不过，没有下次哦"。
  狠话必须由她自己拆穿，且**永远不兑现**（失败可无限重来）。除这一组外，其余文案不许威胁玩家。

系统提示用店长视角；禁止出现"关卡/回合数/奖励池"等裸机制词
（设置面板等纯功能界面除外）。

## 8. 新手教程：房东奶奶的字条（2026-08-13 文案定稿）

教学不做独立教程模式，全部由**房东字条**承载：触发条件满足时弹出一张纸艺字条，
必要时配一个聚光位置（高亮某个按钮/区域），玩家点一下就收起。每张只出现一次
（存档记已读），设置里可「跳过全部」和「重新阅读」。

前提：主角是店长猫；房东奶奶知道这一点，认真把它当能独当一面的孩子，
**不拿"猫当老板"反复开玩笑**。文案温暖、简短，不训人，也不故意卖冷幽默。

### 8.1 主线九张字条

| # | 触发                 | 房东字条                                                                                                                                                                   |
| - | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 3 | 首次产生联动         | "瞧，挨在一起就能互相帮忙。猫猫喜欢有伙伴，客人也更愿意坐在猫猫旁边。"                                                                                                     |
| 4 | 首次出现三选一       | "门口又来了新伙伴，挑一个记进名册吧。不过要记住：你管的是名册，不是座位。每次谁来帮忙、坐在哪里，都要看它们自己的安排。"                                                   |
| 5 | 首次选择结束         | "不合适的伙伴可以先不收。名册越长，每位伙伴轮到上班的机会就越少。小店不大，慢慢挑才好。"                                                                                   |

| 7 | 首次打烊结算         | "今天辛苦啦。流水里有一部分换成了罐头，给你带回家；剩下的要留给房租、水电和明天的生意。"                                                                                   |

### 8.2.1 主动打烊的解锁节奏（2026-08-14）

试营业第一天**不给**打烊按钮：刚接手就学会中途走人，房租的压力立不起来。
第二天开门时解锁，并由上表那张字条说清代价（钱不够照样交不上房租）。

这道锁只为教学服务——**读过那张字条之后**（或玩家主动收起了全部字条），
重开试营业时第一天就直接给。判据是字条已读位，不是局数：头一回就在第一天翻车、
压根没见过那张字条的玩家，重开时仍然该在第二天被教到。

解锁天数走 Settings 的 `tutorial_close_shop_unlock_day`（默认 2）。
